开发集的主要改善来自径向项，正则化增益仅0.067mm且不一致。新测试上无正则径向MAE低0.130mm，但RMSE和δ1更差；正则化径向MAE反而高0.105mm（约1.19%）。正则化径向相对仿射改善2/4视频，视频配对差的描述性95%区间为[-3.048,3.258]mm。它在4/4视频都比无正则径向差，不能声称正则化增强了此次跨域泛化。
