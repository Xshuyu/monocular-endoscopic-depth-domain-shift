## 主要验证路线

优先把论文主张限定为“绝对深度的校准迁移”，尺寸作为独立次要验证。保留所有既有结果；新对象从未参与选择方法、lambda、裁剪范围或图表。

1. 登记实体 object_id 和更高层 independence_group_id。不同肠段若来自同一供体，按供体聚类；同一体模的不同视角、病灶、相机或重复拍摄也保持同组。体模须记录独立制造批次及共享模具，不能据此推断患者泛化。
2. 在看新测试结果前锁定对象清单、文件哈希、权重哈希、所有头参数、相机处理、有效像素定义、深度输出范围、帧抽样规则、排除标准及统计脚本。当前方案未达到此锁定状态。
3. 主实验：现有冻结源域校准头直接迁移到全部新测试对象，不使用新测试 GT 做尺度对齐。新设备自适应作为独立实验，必须使用另外的校准对象，不能从测试对象抽帧校准。
4. 同一冻结 backbone 配 affine LS/ridge 与 radial LS/ridge 为公平主比较；固定主对比 radial ridge 对 affine LS，其余为次要。领域强基线仅在训练重叠核查通过后加入，报告参数量、预训练数据和计算成本；较大模型作为资源不同的参考，不宣称完全等预算。
5. 先计算每帧 MAE，再按固定规则聚合到对象，最后在最高独立层级等权聚合；报告配对差值（radial−affine，负值更好）、区间、每对象散点及失败率。RMSE、AbsRel、深度/半径分层为次要；像素不能充当统计样本。
6. 少量对象时完整展示逐对象差值，不把 bootstrap 得到窄区间当成充分证据。新增研究按独立组抽样的区间应预先指定；跨数据集分别报告，合并仅作次要分析。若多器官来自同一供体，聚类在供体层进行。
7. 主协议沿用已有1–100 mm输出限制时，要明确其适用域并报告参照超界比例。若为新设备扩大范围，需仅依据设备规格/校准对象预先确定，对全部方法一致应用，单独标为新协议，不按测试误差选范围。

## 采集方案（需要真实设备与人员执行）

建议先采集一批独立校准对象和少量工程试拍对象，确认参照可测、误差可接受，再锁定最终测试方案。试拍对象不能转入盲测。预算示例：5个校准对象、20个独立测试对象；这只是采购规划，不代表功效充分，最终数量须依据目标精度和独立组差值的可信先验确定。

- 每个对象按预先设定的中心/中间/边缘位置和近/中/远工作距离取固定数量的视图；失败视图记录原因，不能按算法误差删帧。
- 新设备验证尽量在两个实际独立设备上拍摄同一组测试对象，形成配对设备比较；所有设备的这些对象均留在测试集。仅两台设备不足以推断整个设备总体。
- 每台设备、镜头和分辨率保存标定板原始图、板格毫米值、K、畸变参数、独立标定图重投影误差、裁剪/缩放变换。硬件或成像设置改变应重新标定。相机标定本身不能验证预测深度的绝对尺度。
- 绝对深度需用可追溯的CT/结构光/三维测量参照，记录坐标系、单位、刚体变换及配准不确定度；只允许独立于待测模型输出建立的配准，不按测试预测拟合尺度。
- 若继续声称病灶尺寸：保存与图像同期、同一实体的毫米参照与端点定义。现有 PCA 1–99% 范围不能直接当成卡尺最大径；需预先选择几何一致的参照，或分别报告两种端点。
- 使用已有 physical_size_readiness 模板，建议至少3位盲法标注者、2次分离会话。保持原始重复值，计算绝对一致性 ICC(A,1)；仅对实际采用均值的端点报告 ICC(A,k)。最大值汇总不适用均值 ICC。记录参照仪器分辨率与重复测量不确定度。

## 样本数量敏感性分析

precision_sensitivity.csv 使用 t(0.975,n−1)×假设标准差/√n，近似规划配对对象MAE差的95%区间半宽。假设标准差1/2/3/5 mm、独立测试组5–60，未使用现有两个标本估计方差，不是功效分析或临床阈值依据。例如标准差3 mm时，20组区间半宽约1.40 mm，40组约0.96 mm。若目标是检出很小的优势，需要更多独立对象；增加同一对象视频帧不能替代。

## 准入与交付

填写 object_registry_template.csv（一行一个帧与参照配对），运行 scripts/audit_independent_object_registry.py。门禁只核对记录和文件，不替代人工验证授权、实体身份、参照准确性或配准质量。模板为空时必须失败，不能产出虚假的零误差实验。

尚需用户提供：SCARED 原始授权状态或其他未使用数据目录；若走自采路线，设备、实体对象和可用毫米参照条件。未发送任何数据申请邮件，未生成新的实验精度，未把计划写进手稿结果部分。
