# 径向深度至尺寸测量的物理验证协议（待采集执行）

当前已实现 `scripts/predict_radial_measurement.py`：冻结相对深度→径向校准→毫米轴向 Z→真实标定射线反投影→固定 MAD-PCA 1–99% 尺寸。必须提供匹配的掩膜和标定射线，不猜测 140° FOV。解析测试只验证单位、轴向反投影和接口一致性，不是独立物理验证。

## 尚缺的实际输入

- 具有独立卡尺/扫描仪尺寸参考的病灶体模或临床病灶，以及与图像对应的 ID。
- 所用内镜的内参、畸变/全向模型和有效像素射线；对裁剪和缩放须同步变换。
- 逐图病灶掩膜/测量端点；物理最大直径与算法 1–99% 投影范围不可混作同一终点。
- 原始重复测量和观察者 ID，才能估计标注一致性；不能复用文献 ICC 作为本项目结果。

## 采集与分析顺序

1. 固定设备、头模型、测量端点、掩膜来源和成功/失败规则。将标定物、开发病灶和测试病灶按物理对象分开。
2. 预定义尺寸、距离、倾角和画面半径的组合；每个对象多视角观测只能作为重复测量。样本数应按对象级误差方差与预定义容许误差确定，不由显著性反复追加。
3. 至少两名观察者独立测量并保存原始记录。根据实际设计预先选 ICC 的模型、单次/平均测量及绝对一致性定义，报告置信区间和 Bland–Altman 一致性。
4. 在相同掩膜和射线上配对比较仿射与径向；同时报告实际分割掩膜敏感性，不能只用完美掩膜。
5. 对象等权报告 MAE、偏差、对象聚类区间和预先约定容许误差内比例。记录不可测和失败案例，避免只保留成功测量。
6. 在新设备上的验证单列，不能把同一设备不同视频称为跨设备验证。

本轮不捏造物理标注，不用体模深度 MAE 代替病灶尺寸准确性。此协议是后续真实采集的可执行规范，尚未完成采集或临床验证。
