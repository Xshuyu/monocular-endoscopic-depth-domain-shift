# 后续物理参考与标注一致性验证方案

这是待实施方案，不是已经完成的实验或临床证据。

## 测量目标先固定

分别定义最大直线径、表面路径长度、可见高度；不要用同一个“尺寸”真值评价不同几何量。记录参考仪器分辨率、校准、测量方向、遮挡范围及重复测量误差。合成器的名义尺寸不可自动视为渲染后表面的精确尺寸。

## 物理模体验证

对有独立参考尺寸的多尺寸、多形态模体采集图像。交叉改变工作距离、观察角度、照明和器械姿态；记录真实相机内参、畸变与尺度单位。病灶与器械的深度偏移单独记录。保留失败和拒绝测量的病例，报告覆盖率及全样本结果。

采集前固定主要终点和可接受误差范围。样本量依据先导方差和目标区间宽度确定，不以观察到显著性为停止条件。

## 参考标注一致性

同一对象由至少两位独立观察者分别完成重复测量，观察者不能看到模型预测或对方结果。保留原始每次测量，不只保存平均值。

记录 subject_id、lesion_id、video_id、rater_id、repeat_id、reference_method、endpoint、value_mm、instrument_resolution_mm、timestamp、blinding_status。明确参考量如何汇总，并在测试前锁定规则。

根据目标明确选择单次或平均测量、绝对一致或一致性、观察者固定或随机的ICC模型，并报告95%区间。观察者之间的ICC与模型对参考值的CCC/误差是不同问题。不能从一列真值和一列预测推断参考标注可靠性。对模型报告误差、偏差和一致性界限，并检查误差随尺寸变化。

## 划分及预处理

按患者/视频/模体实例分组，防止同一对象不同帧跨集。相同和近重复图像在划分前建立组。只在训练集拟合跨样本统计量，验证集选择超参数，测试集锁定后只作最终评价。外部测试设备/中心与开发数据分开。图像缩放/裁剪同步更新内参和掩膜变换。
