S3 — Per-frame, per-object and aggregate results

CSV files retain per-frame records; JSON files contain per-object and summary
aggregations for primary scoring, depth strata, target-only calibration,
strong-blur and depth-matched interventions, and pseudo-label controls. Object
and frame identifiers refer to the cited public datasets and do not denote new
independent participants. The parent README and SUPPLEMENTARY_FILE_INDEX.csv
give a short title and description for every data file.
