Supplementary files for
“Monocular Endoscopic Depth under Domain Shift: Calibration, Supervised Adaptation and Controlled Failure Analysis”

This package contains analysis outputs and records generated by this project.
It does not redistribute third-party datasets, pretrained weights, trained
checkpoints, cached dense predictions, or raw audio/video recordings. Obtain
those inputs from the cited dataset/model providers and follow their licenses.
The public source repository is:
https://github.com/Xshuyu/monocular-endoscopic-depth-domain-shift

Files
-----
S1 is supplied separately as supplementary.pdf:
    “Extended scoring and audit tables”: secondary 1–300 mm scoring range for trained regimes and frozen source-only,
    source+target mixed, and target-only calibration heads; complete factorial
    tables, depth-matched blur results, and provenance checks.

S2_protocol_environment/
    “Frozen protocols, environment, validation records, and run logs”.
    - protocol.json: calibration/adaptation revision design, data split and
      hashes.
    - extension_protocol.json: target-only recalibration and strong-blur design.
    - depth_matched_protocol.json: depth-bin matched factorial scoring design.
    - selftrain_protocol.json: pseudo-label control design.
    - environment.json: software and hardware record.
    - training_complete*.json: checkpoint hashes/inventory (not model files).
    - validation_checks*.json: integrity and scoring validation summaries.
    - training_logs/revision/: learning curves and sampled-draw logs for the
      nine source-half, target-only and adapted-double control runs (three seeds
      per regime).
    - training_logs/selftrain/: learning curves and sampled-draw logs for both
      pseudo-label controls (three seeds each).
    - training_logs/parent/: learning curves for the parent source-only and
      supervised-adaptation runs (three seeds each).
    - *.log: calibration fit, inference and control execution console logs.

S3_results/
    “Per-frame, per-object, and aggregate results”. CSV files retain per-frame
    metrics; JSON files provide per-object and cohort summaries for the main
    comparisons, controls, calibration, and image/depth-matched diagnostics.
    Object/frame are identifiers from the public source datasets, not new
    independently collected subjects.

S4_figures/
    “Publication figures and editable vector sources”. Figure_1.pdf–Figure_6.pdf
    are the final figures; radial_architecture.svg and scared_subject_results.svg
    are editable vector sources. Figures are derived from the frozen results.

SUPPLEMENTARY_FILE_INDEX.csv
    “Complete supplementary-file index”: one row per ordinary file with its
    relative path, short title and concise contents description. This is the
    itemized title list for all files in S2–S4.

No project-recorded audio or video excerpts are included. Source dataset videos
and images are not duplicated here; retrieve them from the cited providers.
Model weights, trained checkpoints, raw prediction caches and pseudo-label
caches are also omitted. The repository README describes code entry points and
the additional inputs needed for reproduction.

Reproduction entry points are listed in Appendix A of the manuscript. Dataset
archives and model checkpoints must be obtained separately; paths and hashes
are documented by the experiment protocols and repository README.
